## AI Usage

### какие части делались с AI

- Моки для MSW (на основе openapi.auctions.v0.json)
- Генерация README.md
- Написание unit-тестов
- Финальный Review проекта

### какие решения кандидат принял сам

- Выбор UI-библиотеки
- выбор дизайна для приложения (работал над дубайским проектом для курьерских доставок, взял его как пример)
- технологический стек (требование тестового задания)
- структура проекта (максимально к FSD)
- в принципе все решения приняты мною, AI использовал только для частей выше

### какие AI-предложения были отклонены

- `undefined`, `null` и скрытые значения цены/контактов
- обновление list/detail/bets после mutation
- mobile layout и доступность режима ставки по прямой ссылке

### какие риски остались

- изначально был риск, что не было документации и было сделано по данным из тестового задания. после получения `openapi.auctions.v0.json` были поправлены запросы, ответы, фильтры, enum, nullable-поля, ошибки и MSW-моки

### что бы кандидат улучшил при наличии ещё одного дня

- добавить component/e2e-тесты с Playwright или Selenium
- добавить сортировку, debounce поиска и сохранённые наборы фильтров
- добавить Storybook для карточек и всех edge states
